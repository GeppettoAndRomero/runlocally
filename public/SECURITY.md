# Security

## 日本語

このリポジトリと runlocally.app の脆弱性は、次のどちらかで報告してください。

- GitHub の Security タブ → **Report a vulnerability**（Private Vulnerability Reporting）
- security@runlocally.app

受領の連絡は 72 時間以内、初回の応答は 7 日以内に行います。修正と利用者への告知を調整するため、公開前の協調開示にご協力ください。

## English

Report vulnerabilities in this repository or on runlocally.app through either channel:

- GitHub Security tab → **Report a vulnerability** (Private Vulnerability Reporting)
- security@runlocally.app

We acknowledge reports within 72 hours and send a first response within 7 days. Please coordinate disclosure with us before making details public.
