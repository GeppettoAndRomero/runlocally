# 言語と公開ページ

## 言語の追加

1. 需要の証拠を確認する。
2. ネイティブレビュー体制を用意する。
3. `src/i18n/locales.ts` に `code`、`default`、`hreflang`、`ogLocale`、`name` を登録する。既定言語は一つにする。
4. `src/i18n/<locale>/pages.ts` と `src/i18n/<locale>/ui.ts` を追加する。すべての公開操作の本文と UI キーを埋める。共通 UI キーにはフッターのセキュリティリンクも含む。外枠の文言は `chrome` に置き、`ChromeStringKey` の有限キーと英語参照に対する各言語の欠落・空文字を検査する。従来の `ui` export は `shared` と `workbench`、外枠用の `chromeUi` export は `chrome` を公開する。辞書集約は登録済み言語の両ファイルが欠けるとビルドで失敗する。未登録ディレクトリは公開されない。
5. 生成 HTML、言語選択、相互 hreflang、sitemap を確認する。URL は既定言語のみ prefix を省き、英語ページを `x-default` とする。

公開ページは `LOCALES` と `AVAILABLE_OPS` から生成する。現在はハブ2ページと ZIP の top・4操作を2言語で10ページ、計12ページを生成する。本文と head は初期 HTML に含まれ、ZIP 内で操作や言語を切り替えると同梱辞書を使って外枠のリンク・現在ページ表示も更新する。切り替えは現在の File、一覧、選択、設定、結果、実行中の処理を保持する。戻る・進むは操作と言語を復元するが、過去のセッション状態へは巻き戻さない。再読み込みや別タブをまたぐ File 保持はしない。

`src/seo/url-model.ts` が URL 規則を定義し、`src/seo/page.ts` は公開ページの生成・判定をこのモデルへ委譲する。ハブの生成、公開型・公開判定、head の接続は完了している。

- ハブは日本語 `/`、英語 `/en/`。ZIP トップは `/zip/`、`/en/zip/`。
- ZIP 操作は `/zip/<slug>/`、`/en/zip/<slug>/`。操作部分は `AVAILABLE_OPS` だけから導出する。
- `PublicPage` はハブと ZIP ページ、`ZipPage` は ZIP top と公開4操作だけを含む。公開側の `pagePath()`、`pageUrl()`、`publicPageFromPath()`、`publicPageFromUrl()` はハブを含む。ZIP 専用の `zipPageFromPath()` はハブを拒否する。path 判定は正規の pathname との完全一致、URL 判定は正規の公開 URL との完全一致を要求する。
- 短い slug は `ZIP_SLUGS` に定義し、全11操作の `OPS.slug` がこれを参照する。公開するのは `AVAILABLE_OPS` の4操作だけである。

移行は統合ブランチで順次進める。旧 URL の応答は後続で揃える。sitemap と PWA の12ページ整合は未検証であり、全変更後に CI と3ブラウザーの e2e を確認してから統合する。

Workbench、ZIP 本文の `pageContent()`、動的表示の `displayPage()` は `ZipPage` のみを受け取る。Workbench のクリックと履歴判定は `zipPageFromPath()` を使う。上の File・一覧・結果保持は ZIP 内の遷移に適用される。ハブへの通常遷移には適用しない。ブランドリンクは現時点では ZIP top を指し、ハブへの変更は後続で行う。

File が受理されると `html[data-session="open"]` により説明文を隠す。リセット後は現在の操作と言語の説明文を表示する。操作画面と共通フッターは隠さない。

## 操作の公開

`src/i18n/ops.ts` へ台帳登録し、入力・出力型、形式別ガード、controller の実行と終了処理、UI、本文辞書、アクセシブル名、テストを揃える。その後 `available` を変更し、ページ、タブ、hreflang、sitemap、HTML 件数を確認する。エンジン API の存在だけでは公開しない。

## 検証

`npm run ci` を実行し、生成 HTML の URL 集合と sitemap の URL 集合を照合する。production build の preview で直接訪問、言語・操作・履歴の切り替え、File と結果の保持、入力形式による補正、説明文の再表示、head を確認する。
